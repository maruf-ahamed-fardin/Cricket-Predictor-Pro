Linear Regression

Fits one straight-line weight per input feature. The simplest and fastest model — the baseline that all others must beat. Best for linear relationships like total innings runs.

Fast Interpretable Baseline
🌳

Gradient Boosting

Builds many shallow decision trees sequentially — each one corrects the previous one's mistakes. Captures non-linear patterns and interaction effects between features.

Accurate Non-linear Ensemble
📐

Polynomial Regression

Extends linear regression by adding squared features and cross-product interactions. Bridges the gap between linear and tree-based methods without full ensemble complexity.

📖 Metrics Glossary

MAE ↓ lower is better
Mean Absolute Error

The average difference between predicted and actual values, in the same units as the target (e.g. runs). An MAE of 2.4 means predictions are off by ~2.4 runs on average.

R² ↑ higher is better
R-squared (Coefficient of Determination)

How much of the variance in the target is explained by the model. R²=1.0 is perfect; R²=0 means no better than predicting the mean. Negative values mean it's worse than the mean.

RMSE ↓ lower is better
Root Mean Squared Error

Like MAE but penalises large errors more heavily. A model with low RMSE makes fewer catastrophically wrong predictions.

Confidence ±MAE
Prediction Uncertainty Range

The ±MAE range shown on predictions. If a model predicts 9.4 ± 2.1 runs, it means the true value is likely within [7.3, 11.5] based on test-set performance.

❓ FAQ

Is the data real or synthetic?

The training data is synthetically generated using statistically realistic distributions based on real-world cricket averages (run rates, batting averages, etc.). A real data import module for Cricsheet data is on the roadmap.

Why 3 models at once?

Different models excel at different targets. By running all 3 simultaneously you can see which one fits your scenario best, rather than blindly trusting one algorithm.

What does "Match Phase" mean?

Match Phase is a categorical input: 0 = Powerplay, 1 = Middle overs, 2 = Death overs. It's the most influential feature for runs-per-over predictions.

Can I use the prediction API programmatically?

Yes! Visit API Docs for a full interactive reference. The main endpoint is POST /api/predict.

How are models retrained?

Run python train_models.py locally, or use the Admin retrain web interface if you have the admin key configured.
